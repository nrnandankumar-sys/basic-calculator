# Basic Responsive Calculator

## Overview

The Responsive Calculator is a frontend web application developed using HTML, CSS, and JavaScript. It performs basic arithmetic calculations with a clean and responsive user interface.

This project was created to strengthen understanding of JavaScript logic, DOM manipulation, event handling, and responsive web design.

---

## Features

✅ Addition, Subtraction, Multiplication, Division
✅ Interactive Calculator Buttons
✅ Real-time Result Display
✅ Clear Screen Functionality
✅ Keyboard Support
✅ Responsive Design
✅ Smooth Hover Effects
✅ Modern User Interface

---

## Technologies Used

* HTML5

* JavaScript

## Functionalities

* ✖️ Multiplication
* ➗ Division

### ⌨️ Keyboard Support

Users can perform calculations using keyboard keys.
